**Talent:** 1 female presenter, mid-20s–mid-30s, Indian ethnic, professional blazer, warm expression.
**Camera:** Medium close-up (chest up), eye-level, direct-to-camera.
**Format:** 9:16 vertical, max 8s each.
**Video Folder:** `assets/videos/interview/`

```tsx
  shouldPlay
  onPlaybackStatusUpdate={(status) => {
    if (status.didJustFinish) {
      // show input fields for this step
    }
  }}
  style={styles.video}
/>
```
